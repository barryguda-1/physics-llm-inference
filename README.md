# physics-llm-inference

Hands-on exercises from *The Physics of LLM Inference* (source PDF lives outside the
repo, next to the parent folder). The full text of every chapter is extracted to
[book/](book/INDEX.md) — gitignored, one markdown file per chapter, mapped to the
exercise folders here. When working in an exercise folder, read its matching chapter
in `book/` first; re-extract with `python tools/extract_book.py`.
